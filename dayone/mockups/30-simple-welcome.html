Working with AI · one round · about 45 minutes

Hi Priya. This round is one small, real engineering task, done with an AI assistant.

You'll get a small codebase, a bug report, and an AI assistant that can read the code and suggest changes. We're not testing whether you can write everything from scratch. We're looking at how you understand a problem, how you use the assistant, and whether you check its work.

1
Understand the problem. Read the bug report. Ask the assistant to explain the code. Say what you think is wrong before changing anything.
2
Reproduce it. Run the tests. See the failure with your own eyes.
3
Fix it with the assistant. Ask for a fix. Read it before you apply it. It's fine to disagree with the assistant. It will sometimes be wrong on purpose.
4
Check it works. Run the tests again. Try the example request.
5
Explain in your own words. Three short questions. Plain language is perfect.
