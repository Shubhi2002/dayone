What's different from the full loopOne round, one file set of about 70 lines, one Run button, five fixed steps with a visible checklist, a "Read it first" gate on every assistant change, and copy written for someone who has never seen an assessment like this.
What's the same underneathSame sandbox, same trace, same graders and human review, same eight dimensions (only four carry primary signal here: Debugging, Testing, AI collaboration, Engineering judgment). Same fairness rules: no video, flags never change scores.
Where it fitsNew-grad and early-career loops as the only technical round before a conversation. Also a 30 to 45 minute first screen for mid-level roles, and the free practice tier's default scenario.
