Trace and scoring planewe build · async · doc 07
Event ingestAppend-only trace store

Validates the sandbox token; every event typed and timestamped; Postgres + object storage for replay. Treated as untrusted input.

Snapshot storeRepo snapshots + final diff

Hidden-branch commits every 30 s and on apply; final diff and written answers on submit.

Scoring pipelineNormaliser → signals → rubric agents → reconciler → composer

Five grader runs per item, evidence citations, grader agreement. Anchor sets per scenario.

Calibration queueSampled · flagged · disputed

Human review UI on top of replay. Blind to automated score. Overrides recorded forever.

MonitoringDrift, leakage, fairness

Score drift per scenario, integrity flag rates, adverse-impact screens. Flags route to humans, never to scores.
